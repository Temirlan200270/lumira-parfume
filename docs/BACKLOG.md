# Что ещё можно сделать

Не roadmap «на год» и не целевой UX из [Lumira-Target-State.md](Lumira-Target-State.md). Здесь только то, что **уже намечено кодом** или **дыряво для стойки/покупателя**, с зачем это нужно.

## Админка: добавить товар

Сейчас форма рабочая, но снята с телефона помощника плохо.

| Что | Зачем |
|-----|--------|
| Принимать HEIC и сжимать фото на клиенте | iPhone часто отдаёт HEIC / файлы > 5 МБ — позиция не создаётся |
| Кнопки «Снять флакон» и «Из галереи» | Скрытый `input file` неочевиден за стойкой |
| Кадр под бутылку (кроп 3:4) | Снимки с полки кривые, на витрине режет глаз |
| Цена «за 5 мл», рядом 10 и 20 | За прилавком считают отливант, не ₸/мл |
| Пол без тихого «унисекс» | Легко выложить мужской аромат в унисекс |
| Разлив и распив галочками в одном окне | Иначе одну карточку заполняют дважды |
| Предупреждение, если фото не выбрали | Иначе на сайте пустой прямоугольник |
| Подсказка бренда/имени из уже заведённых | Меньше опечаток Creed / Crivelli |
| После создания открыть строку, а не просто закрыть окно | Понятно, что товар «поехал» |
| В строке витрины: сменить фото, название, бренд | Сейчас только цена, наличие, «на сайте», удаление |

Дубль формата отвечает «Эта позиция уже есть» — лучше сразу открыть существующую строку.

## Два источника каталога

Живая витрина — Supabase. Пакетный состав — `inventory.ts` + `npm run seed:push`.

`seed:push` **выключает все** products/offers, затем поднимает только inventory. Позиция, заведённая только в админке (как разовое фото), после сида станет скрытой, пока её не внесут в `inventory.ts`.

Имеет смысл либо писать админские товары в inventory, либо сид, который не трогает строки не из файла. Иначе стойка «добавила — а после деплоя пропало».

## Карточка товара на сайте

У большинства SKU пустые `description` и ноты: PDP — фото, цена, «в корзину». Админка их тоже не заполняет.

| Что | Зачем |
|-----|--------|
| Поля описания/нот в админке | Чтобы PDP не был пустым после «добавить позицию» |
| Похожие из того же пола и формата, только в наличии | Компонент `SimilarPerfumes` есть, на PDP не висит |
| Избранное на PDP с телефона | Сердце сейчас только desktop; на mobile — только `/favorites` внизу |

«В корзину» только на PDP — так задумано. На сетке объём под ценой, покупка после карточки.
