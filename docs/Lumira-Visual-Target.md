# Lumira — Visual Target

Как выглядит магазин, когда реализован Target State.  
Продуктовая логика — только в `Lumira-Target-State.md`. Этот файл её не меняет.

---

## 1. Visual Direction

Светлая каменная витрина: один реальный флакон, бумага, дневной нейтральный свет. Не Vogue, не чёрный boutique, не маркетплейс.

Если убрать UI, товар держит экран. Если убрать фото, страница кажется пустой.

Тихий каркас, крупное фото, чёрная кнопка, острые углы, воздух между секциями. Зерно почти не видно.

Не: золото, мрамор, сток-женщины, градиентные SVG, мелкие подписи, центрированные карточки, dusty rose как основной цвет.

Max-width 1200. Поля 24 desktop / 16 mobile. Секции 64 / 40. Сетка каталога жёсткая. Hero и PDP асимметричные. Checkout узкий, как письмо.

| Поверхность | Доминирует | Соотношение |
|---|---|---|
| Карточка | фото | 70 : 30 по высоте |
| Hero | фото | 55 : 45 по ширине |
| PDP | фото | 58 : 42 фото / покупка |
| Checkout | форма + счёт | две колонки |

Текст на флакон не кладётся. Header 64 / 56, всегда на месте. Footer `#0c0a09` — единственная тёмная поверхность (фон секции), внизу. Primary-кнопки ink на светлом фоне к этому не относятся.

## 2. Design System

### Typography

**Playfair italic** — только `lumira`. **Geist Sans** — всё остальное. Inter нет. Ниже 12px нет. Единственное типографическое исключение: `PARFUME` в логотипе.

| | Size | Weight | Где |
|---|---|---|---|
| Logo `lumira` | 24 / 20 | 400 italic | шапка |
| `PARFUME` | 10–11, широкий tracking | 300 | рядом с лого |
| Display | 40/48 | 300 | hero |
| H1 | 32/40 | 300 | PDP, checkout |
| H2 | 28/36 | 300 | секции |
| Имя на карточке | 16/22 · mobile 14/20 | 400 | всегда 2 строки |
| Body | 14/22 | 400 | лиды, описание |
| Label | 12, tracking 0.12em | 500 | бренд, поля |
| Цена карточки | 16, tabular | 400 | = масштабу имени |
| Цена PDP | 28 | 300 | |
| Цена / мл | 12–14 muted | 400 | под ценой |
| Button | 14 | 500 | |
| Nav | 13–14 | 400 | |

Цена и имя одного масштаба.

### Color

| | Hex | Роль |
|---|---|---|
| Background | `#fafaf9` | страница, карточка |
| Ink | `#1c1917` | текст, primary, активный объём |
| Muted | `#57534e` | бренд, мл, вторичное |
| Border | `#e7e5e4` | линии, input, табы |
| Accent | `#d4a5a5` | сердце, «Новинка». 1–3 раза на экран |
| Error | `#bf000f` | только ошибка |
| Footer | `#0c0a09` | низ сайта |

Rose никогда не заливает кнопку, hero и активный объём. Золота нет. Магазин светлый: тёмный фон только у футера, primary — ink.

### Spacing

Шкала 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96.  
Карточка: 0 под фото, 12 под текстом. Всё нажимаемое — 44.

Радиус 0 у кнопок и карточек. Input 2px. Теней на карточках нет.

### Buttons, inputs, cards, badges

**Button.** Высота 44. Primary — заливка ink, текст фона. Secondary — обводка. Ghost.

**Input.** Высота 44, label сверху. Ошибка — border + текст под полем.

**Tabs.** Активный — заливка ink. На mobile скроллятся, не сжимаются.

**Card.** Радиус 0, без рамки и тени, текст слева.

**Badge.** Один на карточку. Хит — ink. Новинка — rose. Формат — обводка. OOS — muted.

## 3. Photography

Один SKU — один флакон, один свет, один фон.

**Товар.** Бумага `#f5f5f4`, дневной свет слева-сверху, ракурс 3/4, кадр 3:4. Флакон целиком, горлышко в кадре, лёгкий поворот вправо, мягкая тень вправо-вниз. Серия: одна высота, одна линия стола. Без букетов.

**Hero.** 3–5 реальных отливантов на том же фоне. Группа, воздух сверху. Без текста на фото, без модели, без логотипа на стекле.

**Истории.** Свой тихий кадр или только тип. Не сток-женщина.

**Нельзя.** Сток luxury, чёрный мрамор, 3D, цветные SVG, разный свет в соседних карточках, коллаж.

Пока нет съёмки: плоский `#f5f5f4` и имя. Не градиентный SVG.

## 4. Homepage

Цель: за первый экран объяснить модель — оригиналы по миллилитру. Не сетка из 33 карточек.

Порядок: Header → Hero → Как это работает → Хиты → Разлив / Распив → Trust → Истории → Footer.

```
│ lumira    Каталог  Разлив  Распив  Как это работает    ⌕ ♡ Bag  WhatsApp
│  [ PHOTO ~55% ]     Оригинальная парфюмерия по миллилитру
│                     5 / 10 / 20 мл · Kaspi
│                     [ Смотреть ароматы ]  Как устроен распив
│  1 Аромат     2 Объём     3 WhatsApp · Kaspi
│  Хиты  [3:4] [3:4] [3:4] [3:4]
│  [ Разлив  800 ₸/мл ]     [ Распив  оригинал ]
│  Kaspi · WhatsApp · объём · оригинал
│  Истории → PDP
```

Hero ~75vh. Фото слева, справа display и чёрная «Смотреть ароматы».  
Плитки форматов без фото — не спорят с хитами. «100% оригинал» только на распиве.

Нет наборов, рассылки, квиза, девушки, тёмного full-bleed.

**Mobile.** Фото на всю ширину, текст и кнопка под ним.

## 5. Catalog

Рабочая витрина. Доминирует фото сетки.

**Desktop.** Сайдбар фильтров + сетка: 4 колонки на широком, 3 на tablet. Над сеткой: заголовок по табу, табы, одна строка-лида, поиск, счётчик.

**Mobile.** «Фильтры» открывают sheet снизу. Сетка 2 колонки.

Нет звёзд, хештегов, сортировки «по рейтингу».

### Card

Card. Фото 3:4, занимает примерно 70% высоты карточки. Сердце (♡) и корзина — на фото, справа внизу, всегда видимы, 44.

```
┌─────────────────────┐
│ ХИТ           РАЗЛИВ│
│                     │
│      BOTTLE  3:4    │
│                 ♡ 🛒│
└─────────────────────┘
CREED
Aventus
4 000 ₸
800 ₸ / 1 мл
[ 5 ] [ 10 ] [ 20 ]
```

Один бейдж слева на фото. Чип формата справа на фото, обводка. Имя всегда занимает две строки. Цены tabular, влево.

Hover: лёгкий scale фото, сумка может залиться ink, тени нет.  
OOS: фото бледнее, сумка мёртвая, сердце живое.  
Mobile: те же CTA на фото, объёмы высотой 44.

## 6. PDP

Страница покупки. Первым — флакон. Второй акцент — чёрная «В корзину» на ширину колонки.

**Desktop.** Фото 58% / колонка покупки 42%, sticky. Справа: бренд → H1 → пол · семейство · чип → цена → ₸/мл → объёмы → CTA + сердце → три строки (формат, Kaspi, доставка в WhatsApp).

Ниже на всю ширину: описание, ноты если есть, похожие 4 карточки. Пустых блоков нет.

**Mobile.** Фото 3:4 на всю ширину, покупка столбиком. Sticky `цена + В корзину` над нижней навигацией. FAB нет.

## 7. Cart & Checkout

**Cart.** Desktop: drawer 400px справа. Фото 3:4 в линии, формат, мл можно сменить, итог, чёрная «Оформить заказ». Empty — «В каталог», без disabled primary. Mobile: sheet почти на весь экран.

**Checkout — страница**, не модалка.

Desktop: форма слева, счёт справа. Kaspi выбран текстом, не баннером. Оферта чекбоксом. Primary на ширину формы.

Mobile: счёт сверху, форма ниже, CTA внизу. Нижняя навигация скрыта.

**Success.** Номер заказа, сумма, «Открыть WhatsApp», «В каталог». Не автопрыжок, не конфетти, не зелёная кнопка вместо primary.

## 8. Navigation & Mobile

**Desktop header 64.** `lumira — PARFUME` слева. Каталог, Разлив, Распив, Как это работает. Справа: поиск, сердце, сумка с бейджем, WhatsApp текстом. Без зелёного пузыря, без гамбургера.

**Footer.** Тёмный, три колонки, живые оферта и политика, контакты бренда.

**Mobile header 56.** Лого, поиск, сумка.

**Bottom nav.** Каталог · Избранное · Корзина · WhatsApp. На checkout и success скрыта.

Mobile — отдельная композиция, не сжатый desktop:

- поиск — полный overlay, одно поле, один крестик
- фильтры — sheet снизу
- PDP sticky над bottom nav
- cart — sheet на весь экран
- checkout — своя страница без нижней навигации

## 9. Visual Principles

1. Товар громкий, UI тихий.
2. Фото реальное, одно, в одном свете. SVG не заменяет съёмку.
3. Playfair только в `lumira`. Geist — магазин.
4. Primary — чёрный прямоугольник. Rose редко.
5. Карточка: текст слева, фото 3:4, без тени и скругления. CTA на фото, справа внизу, всегда видимы.
6. Главная начинается с модели покупки. PDP и checkout — страницы.
7. Mobile — отдельная композиция: низ экрана для навигации и покупки.
